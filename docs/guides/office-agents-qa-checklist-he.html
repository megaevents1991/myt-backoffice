מסך תשלום סוכן — 3 כפתורים במקום טוגל (סעיפים 2+5)

  1. צפוי: שלח לינק תשלום ללקוח (ראשי, עם "ההזמנה תישמר 24 שעות") · שלם באשראי שלי (הסוכן) עם סכום החיוב בניכוי · שלם בשובר (רק כשמותר בהסכם). בדסקטופ, מובייל ובפוטר הדביק.
  2. צפוי: לינק ← נוצר hold + שדה העתקה; אשראי שלי ← חיוב אמיתי בסכום המוצג; שובר ← הזמנת Pending. בלי שלב בחירה.
  3. צפוי: הכפתורים ננעלים בזמן שליחה; אין כפולות.
  4. צפוי: "להתחבר מחדש לאזור הסוכן"; שום לחיצה לא מגיעה למסך הקלדת אשראי.
  5. צפוי: כפתור יחיד רגיל; אין 3 כפתורים.
  6. צפוי: שמות/מייל/טלפון מלאים מראש (ניתנים לתיקון) + כפתור מעבר לתשלום. אומת בקוד — לוודא חי.

שיוך ידני — תוקן "לא משויך" (סעיף 3)

ה־dropdown עכשיו 3 מצבים: אוטומטי (לפי הלינק) · שם סוכן · לא משויך (כפוי).
  1. צפוי: השורה מציגה "לא משויך" גם אחרי רענון; נספרת ב"לא משויך" בפילוח ובצבירת המנהל.
  2. צפוי: הזמנה שהוצמדה ידנית וחוזרת לאוטומטי — מציגה שוב את הסוכן מה־UTM.
  3. צפוי: אביב↔איציק — מתעדכן בפילוח, בצבירה ובעמודת האדמין.
  4. צפוי: רשומה עם הערך שנכתב (סוכן / לא־משויך / אוטומטי).

נתוני סוכן בעמוד השותף (סעיף 1)

  1. צפוי: לכל איש צוות — הזמנות / שולמו / מכירות $; ושורת "לא משויך" נפרדת.
  2. צפוי: זהים ל"מכירות לפי סוכן" בדשבורד המנהל, כולל שיוכים ידניים.

וויזרד מלונות — איכות ופילטרים (סעיף 4)

  1. צפוי: תוצאות מ־3★ בלבד; פילטר הכוכבים 3/4/5.
  2. צפוי: מדליקים ← רק מלונות עם חדר בביטול חינם; רשימת החדרים מציגה את המבטלים.
  3. צפוי: מסנן כרטיסים; עובד יחד עם שאר הפילטרים.
  4. צפוי: כרטיס אחד למלון + "חדרים נוספים" עם הפרשים; בחירה נקלטת בסיכום.

הצעת מחיר — פח, תקרה, אחוזים (סעיף 6)

  1. צפוי: הפח על שורת החבילה מנוטרל + tooltip "שורת הבסיס של החבילה"; מחיקת שורות אחרות מחשבת סה"כ נכון.
  2. צפוי: הקלדה מעל המקסימום ננעלת + "עד $X / עד X%"; שליחה מעל התקרה נדחית גם בשרת.
  3. צפוי: טוגל ליד שדה ההנחה בשורת החבילה; ב־% מוצג הסכום המחושב; מעבר מצבים שומר את ההנחה בפועל.
  4. צפוי: הצעה בלי הנחה נשלחת כרגיל; PDF תקין; לינק ההצעה ללקוח עובד.
