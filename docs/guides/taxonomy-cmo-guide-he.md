## 1. מה השתנה (בקצרה)

- לכל תגית יש עכשיו **סוג** (ורטיקל / ליגה / קבוצה / אמן / ז'אנר / עיר / אחר).
- עץ הקטגוריות נבנה מחדש: **3 שורשים** — כדורגל, הופעות מוזיקה, יעדים — עם תתי־קטגוריות.
- נוסף **מנוע תיוג אוטומטי**: כללים שמתייגים אירועים לפי שם האירוע או עיר היעד.
- ה־`custom_label_0-4` בפיד (מטא + גוגל) קיבלו **משמעות קבועה ואחידה** בשני הפידים — אפשר לבנות עליהם פילטרים בקמפיינים.

> ⚠️ **חובה מיידית:** פילטרים קיימים בקמפיינים שמבוססים על ה־labels הישנים **נשברו** ברגע הדיפלוי — צריך לכוון אותם מחדש לפי טבלת ה־labels בסעיף 4.

## 2. איך זה עובד עכשיו — העיקרון

**אף פעם לא משייכים אירוע לקטגוריה.** משייכים לאירוע **תגיות**, וקטגוריה "אוספת" אוטומטית כל אירוע שנושא אחת מהתגיות שלה.

```
אירוע ──נושא──▶ תגיות ──מרכיבות──▶ קטגוריות ──▶ עמודי /c/ באתר + הפיד
```

- דוגמה: אירוע עם התגית `arsenal` נכנס אוטומטית לקטגוריה "ארסנל", וגם מקבל אוטומטית את תגית `football` (ורטיקל) → נכנס גם ל"כדורגל".
- קטגוריה **בלי תגיות** = "hub" — עמוד שמציג רק אריחי תתי־קטגוריות (למשל "ליגות", "יעדים"). זה תקין ומכוון.

### עץ הקטגוריות הנוכחי

```
כדורגל               ← תגית football
├── ליגות (hub)
│   ├── ליגת האלופות · פרמייר ליג · לה ליגה · סריה א · בונדסליגה · ארדיוויזיה
└── קבוצות בולטות (hub)
    └── ריאל מדריד · FC ברצלונה · ארסנל · צ'לסי · פ.ס.ז' · אינטר · אתלטיקו ·
        טוטנהאם · ניוקאסל · מנצ'סטר סיטי · מנצ'סטר יונייטד · ליברפול · באיירן

הופעות מוזיקה         ← תגית music
├── ז'אנרים (hub)
│   └── פופ · רוק · היפ הופ · רוק קלאסי · קלאסי · קאנטרי
└── אומנים (hub)
    └── סלין דיון

יעדים (hub)
└── לונדון · פריז · מדריד · מילאנו · ברצלונה · אמסטרדם · ברלין · מינכן ·
    פראג · ליסבון · רומא · דיסלדורף
```

## 3. סוגי תגיות

| סוג | דוגמאות | לאן זה הולך בפיד |
|---|---|---|
| ורטיקל (vertical) | football, music | `custom_label_0` |
| ליגה (league) | premier-league, champions-league | `custom_label_1` |
| ז'אנר (genre) | pop, rock, hip-hop | `custom_label_1` (אם אין ליגה) |
| קבוצה (team) | arsenal, real-madrid | `custom_label_2` |
| אמן (artist) | celine-dion | `custom_label_2` (אם אין קבוצה) |
| עיר (city) | london, paris | `custom_label_3` |
| אחר (other) | כל דבר פנימי | לא נכנס ל־labels (כן ל־internal_label) |

**מה לא תגית בכוונה:** חודש האירוע, זמינות, הרכב חבילה — אלה מחושבים אוטומטית מנתוני האירוע ולא מתויגים ידנית (כדי שלא יתיישנו).

## 4. הפיד — מה כל שדה מכיל עכשיו (לבניית פילטרים)

| שדה | מכיל | דוגמה |
|---|---|---|
| `custom_label_0` | ורטיקל | `football` / `music` |
| `custom_label_1` | ליגה או ז'אנר | `premier-league` / `pop` |
| `custom_label_2` | קבוצה או אמן | `arsenal` / `celine-dion` |
| `custom_label_3` | עיר יעד | `london` (אם אין תגית עיר — קוד IATA באותיות קטנות) |
| `custom_label_4` | זמינות | `available` / `sold_out` (בפיד ה־Activities תמיד `available` — אזל־מלאי לא נכלל בו בכלל) |
| `product_type` | שרשרת הקטגוריות | `Football > Leagues > Premier League` |
| `internal_label` (XML בלבד) | כל התגיות + סטטוס | `arsenal`, `status:available` |
| `custom_number_0-2` (XML) | שנה · ימים־עד־אירוע · לילות | `2026 · 45 · 3` |

**דוגמאות פילטר בקמפיין:**
- כל הכדורגל: `custom_label_0 = football`
- רק פרמייר ליג: `custom_label_1 = premier-league`
- חבילות ארסנל: `custom_label_2 = arsenal`
- כל מה שבלונדון: `custom_label_3 = london`
- להחריג אזל: `custom_label_4 = available` (בפיד המסחרי/גוגל)

אותה סכמה **בשני הפידים** (meta-catalog.xml לגוגל, meta-activities.csv למטא).

## 5. מה עושים ואיפה — מסכים

### א. תגיות — `Tags (תגיות)` בסיידבר
- יצירה: שם בעברית + **שם באנגלית (חובה — הוא הופך ל־slug בפיד)** + בחירת **סוג**.
- עריכה: שינוי שם / סוג / הפעלה־כיבוי. תגית כבויה נעלמת מהפיד ומהפילטרים באתר.
- סינון לפי סוג בראש הרשימה.

### ב. כללי תיוג אוטומטי — `Tag Rules (כללי תיוג)` בסיידבר
- כלל = "אם שם האירוע מכיל X → תן תגית Y" או "אם עיר היעד (קוד IATA) היא X → תן תגית Y".
- דוגמה: `Arsenal` בשם → תגית `arsenal`; עיר `LON` → תגית `london`.
- רץ **אוטומטית על כל אירוע חדש** שנוצר. כפתור **"Run rules on all events"** מריץ על הכל.
- הכללים רק **מוסיפים** תגיות — לעולם לא מוחקים. תיוג ידני לא נדרס.
- מה שכבר מכוסה בכללים: 28 ערים, 13 קבוצות, ליגת האלופות, סלין דיון + השלמת ורטיקל אוטומטית (ליגה/קבוצה→football, ז'אנר/אמן→music).

### ג. קטגוריות — `Templates → Categories`
- קטגוריה חדשה = כרטיס (תמונה, כותרת) + מיקום בעץ (הורה) + **התגיות שמרכיבות אותה**.
- קטגוריית hub = בלי תגיות, רק ילדים.
- מתג `is_active` אחד מפעיל גם את האריח בדף הבית וגם את עמוד `/c/`.

### ד. תיוג אירועים — מסך `Events`
- עריכת אירוע בודד → בחירת תגיות (הקטגוריות מחושבות ונצבעות אוטומטית).
- סימון כמה אירועים → פעולה מרוכזת Add / Replace / Remove תגיות.
- פילטר **"ללא תגיות"** ברשימה — מציג את מי שנשאר בלי כלום. לשאוף ל־0.

## 6. תהליך עבודה לאירוע חדש (מה־CMO או מנהל התוכן)

1. האירוע נוצר → ערים + קבוצות מוכרות + ורטיקל מתויגים **אוטומטית**.
2. ידני (מה שכללים לא יודעים):
   - אירוע כדורגל → תגית **ליגה** (שם המשחק לא מכיל את הליגה).
   - הופעה → תגית **ז'אנר**, ואם זה אמן שרוצים לקדם — ליצור תגית אמן + כלל.
3. בדיקה שבועית: פילטר "ללא תגיות" → לרוקן.

### אמן חדש שרוצים לקדם (למשל קולדפליי)
1. Tags → תגית חדשה: "קולדפליי" / `Coldplay` / סוג **אמן**.
2. Tag Rules → כלל: שם מכיל `Coldplay` → התגית. → Run all.
3. (אופציונלי) Templates → Categories → קטגוריה "קולדפליי" תחת "אומנים" עם התגית.
4. בפיד: `custom_label_2 = coldplay` מוכן לקמפיין.
