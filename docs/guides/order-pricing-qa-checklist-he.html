מחיקת הזמנות — חדש, superadmin בלבד

מחיקה היא רכה: השורה מסומנת בתאריך ונעלמת מהרשימה, אבל נשמרת במסד ואפשר להחזיר אותה. אין מחיקה קשה.
  1. צפוי: בעמוד ההזמנות — אייקון פח בכל שורה, כפתור Delete אדום בפעולות המרובות, צ׳קבוקס Show deleted ועמודת Deleted.
  2. צפוי: אותו עמוד בדיוק בלי אייקון פח, בלי כפתור Delete, בלי Show deleted ובלי עמודת Deleted. איך: התחבר כמשתמש admin או editor רגיל. קריטי לאבטחה — אם משהו מזה מופיע, עצור ודווח.
  3. צפוי: אייקון פח ← דיאלוג אישור ← השורה נעלמת מהרשימה, טוסט "Deleted".
  4. צפוי: סימון הצ׳קבוקס ← ההזמנה חוזרת לרשימה, בעמודת Deleted מופיע התאריך (08-24-2026), ואייקון הפח כבר לא מוצג עליה.
  5. צפוי: סימון כמה שורות ← Delete ← אישור ← כולן נעלמות יחד, טוסט עם המספר הנכון.
  6. צפוי: כניסה להזמנה מחוקה ← באנר אדום "marked as deleted on …". ההזמנה עצמה עדיין נפתחת ונקראת.
  7. צפוי: מזהים 1820-1849 (הרשימה שנמחקה ב-24.08) לא מופיעים ברשימה הרגילה, ומופיעים עם תאריך כש-Show deleted מסומן.
