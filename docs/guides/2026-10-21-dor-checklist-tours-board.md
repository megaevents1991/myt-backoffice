## 1. מי אחראי במגה פמילי (לפני שאלון נכנס) - 2 דקות

הכלל החדש: **אחראי** (admin) רואה את כל הקארדים ומשייך במכה; **נציג** רואה רק את שלו + לא משויכים.
אחראי = חשבון עם role גלובלי `admin` / `superadmin`, **או** חברות `admin` בחברה מגה פמילי.

1. בק-אופיס ← **Users** ← בחר חברה **מגה פמילי** (בורר החברה למעלה).
2. אלון (ומי שעוד מנהל) ← role בחברה: **admin**. (רק superadmin יכול לתת admin.)
3. נציגים רגילים נשארים `editor` / `tours_agent`.

בלי זה אלון יראה רק את הקארדים שלו ולא יהיה לו "Set rep…" בבאלק.

## 3. ZeptoMail (Zoho) - דומיין שולח למגה פמילי - 15 דקות

היום הבק-אופיס שולח דרך ZeptoMail רק מ-`alon@mega-events.co.il` (`lib/email.ts`). כדי שאישור הזמנה / קבלה / חומר לטיול ייצאו **מהמייל של מגה פמילי** צריך דומיין שולח מאומת:

1. https://mailagent.zoho.com (ZeptoMail) ← **Mail Agents** ← ה-Mail Agent הקיים (או **Add Mail Agent** "Mega Family").
2. **Domains** ← **Add Domain** ← הדומיין של האתר של פמילי (זה שבכתובות המייל של הצוות).
3. ZeptoMail נותן רשומות DNS: **DKIM** (CNAME/TXT) ו-**SPF** (TXT `v=spf1 include:zeptomail.net ~all` - אם כבר יש SPF לדומיין, מוסיפים את ה-include לרשומה הקיימת, לא רשומה שנייה). להוסיף אצל רשם הדומיין ← **Verify**.
4. **SMTP** ← אם זה Mail Agent חדש: **Generate credentials** ← לשמור את המשתמש והסיסמה ב-Vercel (בק-אופיס) כמשתני סביבה חדשים, למשל `NEXT_SECRET_EMAIL_FAMILY_USER` / `NEXT_SECRET_EMAIL_FAMILY_PASSWORD` (אם משתמשים באותו Mail Agent - אין צורך, הקיים מספיק).
5. כתובת השולח: להחליט מה הכתובת (למשל `office@<דומיין פמילי>`) - צריכה להיות תחת הדומיין שאומת.

**מה לא מחובר בכוונה (הסיבוב הבא):** השליחות עצמן - אישור הזמנה, קבלה, חומר לטיול - מהמייל של החברה עם CC לנציג. היום "שליחת אישור" הוא צ'קבוקס, המעטפה בלוח פותחת את תוכנת המייל של הנציג (mailto). ברגע שהדומיין מאומת זה כיום עבודה: תבנית לכל שליחה + כפתור בעמוד הקארד + רישום "נשלח" על ההזמנה + `cc` ב-`sendMail`.
