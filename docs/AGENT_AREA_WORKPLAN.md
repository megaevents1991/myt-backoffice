## ✅ בוצע (2026-08-05)

- **שלושת אמצעי התשלום במצב סוכן** (main): לקוח משלם / כרטיס סוכן (נטו, מציג −X% עמלה) /
  שובר — מוצג רק כשיש שובר חי, נצרך בהזמנה ונרשם כקופון כך שה-ledger מתחשבן (Paid = נוצל).
- **מצב סוכן לכל סוכן** — הוסר התנאי commission > 0 (`isAgentVisitor = affType === "agent"`).
- **הצעת מחיר חתומה**: לינק התשלום נושא `&quote={id}&qsig=HMAC` — main מציג את ההצעה
  (שורות + סה"כ) וגובה את הסכום של הסוכן; הצעה שפגה → באנר + מחיר חי. חתימה = כל בקרת הגישה.
- **לוגו שותף**: פס "בשיתוף {שם}" בעמוד ההזמנה לפי `utm_source`.
- **Handoff פורטל→מיין**: טוקן 10 דק' → `/api/partner-handoff` → סשן שותף שבועי במיין.
- **נעילת חבילה**: UI בחירה ברור באשף ("+ להוספה"), toggle נעילה ברשימה, הבעלים עוקף נעילה.
- **מחיר חי באשף**: הבר התחתון מציג כמות × מחיר לנוסע, עם הגנת race על שינוי כמות באמצע חיפוש.
- **Login-as-agent** לסופראדמין מטבלת השותפים (סשן התחזות שעתיים, audit-logged).
- **Multi-session**: סשן שותף בעוגיית `portal_session` (path=/portal) לצד סשן אדמין — לא מפילים זה את זה.
- **תיקון "3 השגיאות" בכניסת סוכן** — redirect ישיר לפורטל לפי role, בלי הבזק דשבורד.
- **סקירת באגים מלאה** — 15 ממצאים תוקנו (open redirect ב-handoff, פקיעת טוקן התחזות,
  ספירת Paid כפולה ב-funnel, ועוד).

צ׳קליסט QA מלא (8 זרימות): ראה artifact "אזור סוכן — בדיקות QA" בסשן, או בקצרה:
כניסת סוכן נקייה → login-as-agent + ריבוי סשנים → אשף (מחיר חי + נעילה) → הזמנה עבור
הלקוח → 3 אמצעי תשלום → שובר↔קרדיט → הצעה חתומה (כולל זיוף/פקיעה) → לוגו שותף.
