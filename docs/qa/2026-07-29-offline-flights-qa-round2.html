Where to test

both surfaces are live

The main app is merged and deployed, so the customer flows can be checked on the real site rather than localhost — which is the better test, since that's what customers hit. For the backoffice flows, either production or npm run dev on port 3000 is fine; both run against the same database.

Use a test event for anything involving a lock. Locking now takes effect immediately for real customers — a locked package with no seats shows as sold out and stops selling. That's correct behaviour, and exactly why you don't want to try it on an event people are buying.

Allocations carry the same weight: setting one to 0 on a live event hides that flight from real searches straight away.

B7b

A deleted series leaves the filter

Item 1 · stale filter options

"אם מחקתי את הסדרה שלא תופיע כבר בפילטר של הסיריס יותר"

  1. Create a small series, then delete all of its flights.
  2. Open Filters → Series.
  3. Now do it the other way: filter by a series, then delete its flights while the filter is on.
  4. Turn on Show deleted and check the dropdown again.

Expect: the dead series is gone from the list, and an active filter that empties out clears itself rather than leaving you on a blank table wondering why. With Show deleted on, deleted series reappear as options — because now they match something.

B10

The Save bar only appears for changes you made

Event page dirty state

"זה קופץ איך שנוגעים בזה - צריך רק אם יש שינוי"

It was real, not cosmetic: editing a flight's price rewrites the event's base_flight_price server-side, and the page counted that as your unsaved work.

  1. Open an event with linked flights. Don't touch anything — no Save bar.
  2. Inline-edit a flight's price in the flights card.
  3. Now edit something on the event itself — the name, a markup.
  4. Undo that by hand, back to the original value.

Expect: no Save bar after step 2, Save bar after step 3, gone again after step 4. The event's base flight price still updates from the flight — it just no longer pretends you have unsaved work.
