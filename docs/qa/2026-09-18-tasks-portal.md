## 3. מיילים (צריך שני משתמשים - א' מנהל, ב' עורך)

| # | מה לעשות | מי אמור לקבל מייל |
|---|----------|-------------------|
| 3.1 | א' יוצר משימה ומשבץ את ב' | ב' - "משימה חדשה". ההודעה הקופצת אצל א': "An email went out to the assignee" |
| 3.2 | ב' מגיב במשימה | א' (היוצר). ב' עצמו לא מקבל |
| 3.3 | א' מגיב במשימה | ב' (המשובץ) |
| 3.4 | א' מגיב עם `@ב'` | ב' מקבל מייל **אחד** (אזכור), לא שניים |
| 3.5 | ב' מסמן Done | א' - "בוצע: ..." |
| 3.6 | א' מסמן Done במשימה שהוא עצמו יצר | אף אחד (לא שולחים לעצמך) |
| 3.7 | הלינק בכל מייל | נפתח `/tasks?task=<id>` על המשימה עצמה |

אם מייל לא הגיע: Vercel → backoffice → Logs, לחפש `tasks:` - כל שליחה נרשמת כ-
`mail sent` / `skipped` / `failed` עם הכתובת. `sent` ולא הגיע = ספאם או חסימה ב-ZeptoMail.
